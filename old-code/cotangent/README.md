# Starting point: from combinatorics to algebra

This directory contains the scripts needed
to pass from the abstract simplicial complex
$M$ discovered in the [1967
paper](https://doi.org/10.1016/S0021-9800(67)80055-3)
to the commutative algebra objects we work
with. These are the pillars of the project;
everything is built upon them and a mistake
here would be fatal.

In this note I describe only the scripts
I worked with the most.

* Everything starts in `M_FACETS.py`,
the script in which the combinatorial
information of the simplicial complex
$M$ is hardcoded.

* `part-1.sage` turns the raw combinatorial
data into commutative algebra objects.
Here we define the Stanley-Reisner ideal
of $M$, which is the monomial ideal $I$ in
$k[x_1,…,x_8]$ generated by
```
x6*x7*x8, x4*x6*x8, x3*x7*x8, x3*x5*x7,
x3*x4*x8, x2*x7*x8, x2*x5*x7, x2*x5*x6,
x2*x4*x7, x2*x4*x6, x1*x4*x6, x1*x4*x5,
x1*x3*x8, x1*x3*x6, x1*x3*x5, x1*x2*x5.
```

This script further computes the general
form of a (degree-zero, embedded)
first-order deformation of this ideal
as follows.

1. We add to every monomial generator a
   linear combination of the remaining $104$
degree-3 monomials which are not the
generators. (There are in total
$120=\binom{10}{3}$ degree-3 monomials, and
we subtract the 16 generators.) This means
that a general deformed polynomial depends
on $16\cdot 104=1664$ parameters.

2. We impose that a general deformed
   polynomial satisfies the same syzygy
equations as the original ideal. This
amounts to a set of relations among the
parameters, leaving only 109 free
parameters. See [Lectures on Deformations of
Singularities, Michael Artin, Proposition
3.1].

The latter computation takes some time, so I
designed this script, `part-1.sage`, to
store the data in a Pickle file `part-1.pkl`
so that other scripts could load the data
directly without computing every time.
The reason for the name `part-1` is
historical---there's no part 2.
