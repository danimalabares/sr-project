# Serendipity cubic family

This directory studies a cubic family over
$\mathrm{GF}(32003)$ that was discovered
while constructing the deformation-search
environment in `code/rl`. The family has
been frozen as explicit polynomial data, so
this project does not depend on the RL
machinery or rerun a lifting solver.

The first-order direction that led to the
family is:

```sage
y[0] = 1403
y[2] = 30586
y[3] = 25586
y[19] = 4225
y[33] = 3849
y[34] = 8966
y[41] = 27546
```

The data define 16 exact cubics

```text
F_i=f_i+t g_i+t^2 h_i+t^3 q_i
```

in $\mathrm{GF}(32003)[t,x_1,\ldots,x_8]$.
The family is flat near $t=0$: the exact
colon calculation gives

```text
J:t=J.
```

Flatness does not imply that a nonzero fibre
is smooth. The smoothness script specializes
to $t=1$, computes the fibre invariants, and
applies the projective Jacobian criterion
after removing the affine cone vertex.

Run from the repository root:

```sh
sage serendipity/verify_flatness.sage
sage serendipity/test_smoothness.sage
```

The frozen Sage object and a readable list
of all generators are in `data/`.

## The fibre at $t=1$ is singular😭

The script `test_smoothness.sage`
specializes the family to $t=1$.

The resulting fibre has:

```text
affine-cone dimension: 4
projective dimension: 3
codimension: 4
degree: 20
Hilbert polynomial: 10/3*t^3 + 14/3*t
```

Thus it has the expected dimension and
degree.

To test smoothness, the script computes the
Jacobian matrix of the 16 generators and
forms the ideal generated by the appropriate
$4\times4$ minors.

It then saturates by the irrelevant ideal to
remove the vertex of the affine cone and test
the projective variety itself.

The result is:

```text
projective singular locus empty: False
smooth: False
```

Therefore, the fibre at $t=1$ is singular
over $\mathrm{GF}(32003)$.

This does not yet prove that the generic fibre
is singular. It only proves that this
particular nonzero fibre is singular.

The next step is to test other nonzero values
of $t$, or to compute the relative singular
locus of the entire family and determine
which values of $t$ correspond to singular
fibres.
